a practice ladder, not a syllabus

From print() to the level past your hardest problem

Your seven problems and two SQL joins all sit at roughly the same difficulty: a class holding a list of another class, with one or two methods that search, filter, or sort it, fed by a fixed stdin format. Call that level n. This ladder builds up to it from plain Python, pushes one rung past it into level n+1 (multi-class systems), and one more into n+2 (mini in-memory databases, design patterns, testing, concurrency) — plus two dedicated tracks: a full SQL path (SELECT through window functions) and a Unix AWK path (fields, patterns, and reports), using the same Employee/Department data throughout so you can compare the SQL, Python, and AWK ways of asking the same question. Every question has a solution you can reveal — but it'll ask what you're doing first.
